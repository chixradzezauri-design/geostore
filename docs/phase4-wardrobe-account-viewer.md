# 4BN — gated account wardrobe viewer
Actual wardrobe page now mounts a lazy account collection panel only when a new compile-time flag is enabled (false). Reads use verified auth user and owner-bound RPC; strict metadata shape, 100-item limit, unique UUID, private owner-only photo paths, monotonic revisions and late response rejection. Photos are downloaded only on explicit request after refreshing item membership, validated by existing private transport and displayed in a transient object URL revoked on replacement/unmount. No public links, automatic upload, local import, deletion or mutation. Existing device wardrobe stays unchanged; legacy demo items never uploaded. Same-owner token refresh and actual hosted Storage response/cache behavior, privacy-preserving photo metadata stripping, quota reservations/upload lifecycle, erasure and real Auth/two-device browser tests remain blockers. No server migration or deployment.
