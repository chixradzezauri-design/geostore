# 4AM — staged MFA presentation
Responsive standalone panel in Georgian, English and Russian. Manual TOTP key entry only, no raw QR SVG injection, no secret persistence or logging. Six ASCII digits with leading zeros, explicit verification, accessible status, verified-factor choice, scope-keyed remount and stale response discard. Successful verification requests a fresh session/role/AAL decision, never grants access. Recovery guidance recommends another already verified authenticator or authorized identity verification; there is no custom bypass or implemented recovery service. A lost unverified enrollment requires deliberate support handling, not automatic re-enrollment. No App mount, backend enforcement, backup factor management or active MFA changes. Real browser integration, secret cleanup and auth-session coordinator tests remain mandatory before release.
