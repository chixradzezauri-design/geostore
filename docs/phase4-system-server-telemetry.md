# 4AZ — trusted server telemetry and warning candidate
Existing catalogue and sitemap handlers submit only three fixed server failure codes via private server-only module. Disabled unless GEOSTORE_SYSTEM_MONITOR_ENABLED=true and GEOSTORE_MONITOR_SUPABASE_SECRET contains a server-only new Supabase secret key. No credentials set or printed. At most one observation per code per minute per warm instance and one in-flight request, no retries, 750ms timeout; only failure paths, preserve original response. Counts are sampled; cross-instance global rate limiting/abuse protection remains a release gate (public requests may trigger upstream failure). No public telemetry write endpoint or browser upload. Owner history panel warns on three or more sampled same-code server observations this UTC hour. No push/email, no claim of outage. Five tests. Requires 4AY SQL, real Data API verification and owner panel mount, retention job and release approval. No live change.
