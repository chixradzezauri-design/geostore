# 4BK — gated cart reconciliation panel
Cart page integration for authenticated non-admin users, lazy and compile-time disabled. Explicit comparison of local/account line identities and quantities. Only exact current local intent can be published after separate confirmation, using existing journal and CAS, with current verified catalogue checking full candidate remote cart's aggregate stock per product/variant (including different add-ons), matrix identity, required size/color and publication status. Reject private gift text, ambiguous identities, stale quantities and unavailable catalogue. No price, contact data or checkout data uploaded. Account-only rows are visible for review, not automatically imported or removed. Retry and exact-entry discard are explicit. Local cart and checkout remain unchanged. Stock checks are client advisory and do not reserve stock; server-side variant validation, authoritative hydration, remote deletion, receipt reconciliation, cross-tab persistence and real Auth/two-device tests remain necessary before enabling. Previous head browser CI pending at preparation time. No migration/deployment.
